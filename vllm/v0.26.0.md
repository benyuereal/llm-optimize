## 本版导读

0.26.0 在 0.25 换完底盘之后，主题转向"在新底盘上深挖性能"。第一主线是 **DeepSeek-V4 端到端延迟持续压榨**（专用路由内核 TPOT -2.94%、fused_topk_bias 提速 1.5~2x、去冗余 -1.8%，DSv4 DSpark 投机解码登陆 AMD/XPU）。新模型阵营集中登场：**Inkling 家族自带 MTP=1 投机解码**（新模型从设计就内建投机解码），多模型迁到 Transformers 建模后端。引擎核心补硬骨头（fp32 生成头、KV 二级存储成熟），并做了安全加固（移除 diskcache 消除 pickle 风险）。配套 Transformers 5.13.0，升级注意依赖门槛。

## 头条亮点

1. **DeepSeek-V4 端到端延迟持续打磨（本版第一主线）**
   - 专用路由内核把 E2E TPOT 再降 **2.94%**（`b5433b6f5` #48660）；`fused_topk_bias` 路由 kernel 提速 **1.5~2x**（`2dab187f7` #47463）；去除冗余 repeat/copy 再降 TPOT **1.8%**（`442c421e7` #48137）。
   - ROCm 侧 DSv4 sparse attention prefill kernel、两阶段 compressor kernel、split sparse decode（gfx942/gfx950）相继落地；DSv4 DSpark 投机解码登陆 AMD（MI350X/MI355X）与 Intel XPU，跨硬件铺开。

2. **Inkling 模型家族完整合入（含 MTP=1 投机解码）**
   - 4 篇连载 PR（[1/N]~[4/N]，`6570c9800` #48799 / `251f7e478` #48822 / `fb5ec0dc9` #48869 / `f3e9497e9` #48884）依次落地基础模型支持、Piecewise CUDA Graph、**MTP=1 投机解码**、LoRA，并补 Hopper FA4 相对位置注意力与标准 ModelOpt NVFP4 配置。

3. **多模型迁移到 Transformers 建模后端，配套 Transformers 5.13.0**
   - `Bump Transformers version to 5.13.0`（`4a6440ace` #47867）作为基线；Olmo/Olmo2（`b83be00cd` #48100）、MistralLarge3（`fabec87f6` #48153）、HunyuanVL（`51e5372f3` #47872，改用原生 transformers processor）陆续迁到 Transformers 建模后端 / AutoWeightsLoader。

4. **引擎核心：fp32 生成头、按 KV-cache 组选 attention 后端、KV 二级存储成熟**
   - `head_dtype` 支持 fp32 lm_head 生成头（`107a03ba6` #48390），并扩展到 LoRA 路径（`4f7fffb92` #48525）；attention 后端可按 KV-cache group 分别选择（`5784507da` #48012）；KV 卸载与二级存储（FS/OBJ tier）补齐 ParentManager、tier-owned 事件、tier locality、metrics、DP-replica 感知、P2P 默认端口等，进入"可用"阶段。

5. **安全加固：移除 diskcache 消除 pickle 反序列化风险**
   - `Replace diskcache to eliminate pickle deserialization`（`96d2ceda4` #44549）用安全实现替换基于 pickle 的 diskcache；并修复并发稀疏不变量竞态绕过 CVE 缓解（`793cf79c8` #48583）。本版另移除 TeleChat、Persimmon、Fuyu 三个旧模型架构。
